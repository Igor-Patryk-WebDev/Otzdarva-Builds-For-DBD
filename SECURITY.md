# Security Policy

## Supported Versions

We currently support only the latest version of the project.

| Version | Supported          |
| ------- | ------------------ |
| 3.0     | :white_check_mark: |

We do not maintain or support older versions, and there are currently no active branches containing older releases.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately by sending an email to:

`patrykigor.webdev@gmail.com`

Please **do not publicly disclose the vulnerability** before we have had an opportunity to investigate and address it.

When reporting a vulnerability, please include as much of the following information as possible:

- A clear description of the vulnerability.
- The affected version or component.
- Steps required to reproduce the issue.
- A proof of concept, if available.
- The potential security impact.
- Any relevant logs, screenshots, code snippets, or other technical details.
- A suggested fix or mitigation, if you have one.

## What Happens After You Report

We will review the report and investigate the issue as soon as reasonably possible.

If the vulnerability is confirmed, we will work on a fix and determine whether a new release is required. We may contact you if additional information is needed to reproduce or understand the issue.

Please allow us reasonable time to investigate and resolve reported vulnerabilities before making the vulnerability public.

### Thank you for helping us keep the project secure.
